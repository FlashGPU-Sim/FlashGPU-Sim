# Blackwell indirect launch parameters

SM100/103 compiler-generated by-value tensor-map accesses read the launch
parameter pointer from constant bank zero at `0x348`. This adapter exposes the
existing indirect parameter window at that location, using the same launch
parameter backing as direct constant loads. It does not copy arguments into a
second allocation. SM90 retains its `0x198` pointer and SM120 keeps `0x348` zero.

`SassParameterAlias` checks SM100 and SM103 reads, coherent parameter updates,
read-only aliases, the last parameter byte and the following ordinary global
address. Its build uses the same OpenMP class-layout flag as existing tests
that instantiate `kernel_info_t`. The original captured projection additionally
advances beyond its first parameter-addressed TMA after this repair; its later
unmigrated instructions are separate acceptance gaps. No whole-kernel numerical
pass is claimed by this ABI repair.
