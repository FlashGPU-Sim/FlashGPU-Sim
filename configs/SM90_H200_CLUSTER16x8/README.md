# SM90_H200_CLUSTER16x8

Leftover uniform 8×16 = **128 SM** packing. **Do not use this as the
full-chip default.** Published cycle numbers and calibration scripts use
`SM90_H200_CLUSTER132`. Functional cluster tests use
`SM90_H200_REDUCED_CLUSTER16x2`.

This directory remains so old run directories can still resolve the config
name. New work should not add references to it.

Design: `docs/cluster_noc/README.md`.
